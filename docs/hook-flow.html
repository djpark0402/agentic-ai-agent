.claude/hooks/
6개 .sh 스크립트
라이프사이클 훅 (자동화 엔진)
→ 각 라이프사이클 이벤트에서 harness가 stdin으로 이벤트 JSON을 주며 실행. 훅이 stdout으로 JSON 반환해 Claude 동작에 개입.
  • session-start.sh · check-branch.sh · check-merge.sh
  • post-lint.sh · post-compact.sh · auto-commit.sh
  • 브랜치 보호 / 자동 커밋 / lint 게이트 / 압축 규칙 재주입
🔒
.claude/settings.json
훅 등록 + permission
훅 매니페스트 + 권한 체계
→ 훅 스크립트를 어떤 이벤트 · matcher에 연결할지 선언. 도구 실행 전 PermissionRequest에서 deny/ask 규칙 검증.
  • hooks: SessionStart / PreToolUse / PostToolUse / Stop / PostCompact 등록
  • deny: Edit(**/.env), Write(**/.env)
  • ask: Bash(git push), Bash(git push:*)
어떻게 접목되는가 — 세션 시작 시 settings.json이 훅을 등록하고, harness가 CLAUDE.md를 읽어 시스템 프롬프트에 넣습니다. 이후 Claude가 Edit/Write/Bash 같은 도구를 호출할 때마다 hooks/*.sh가 라이프사이클 이벤트에서 자동 실행되고, agents/는 Task 도구로 특정 영역(backend/frontend) 작업을 위임할 때 페르소나 프롬프트로 쓰입니다.
